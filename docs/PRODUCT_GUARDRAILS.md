# Product Guardrails: Daily Hype Battle

To comply with Reddit Platform Policies, App Store guidelines, and local regulations regarding interactive applications, this project must strictly adhere to the following product guardrails.

---

## 🚫 Core Boundaries
* **This is NOT Gambling**: There is no entry fee, no wagering, no odds, and no financial payout. It is a social prediction game.
* **This is NOT Crypto**: There are no blockchain transactions, no non-fungible tokens (NFTs), and no tokenized incentives.
* **This is NOT Finance**: The app does not simulate mock financial markets, trading, asset buying, or stock prices.
* **This is NOT Connected to Reddit Karma**: Votes inside this application do not modify the user's actual Reddit post/comment karma.

---

## 🛑 Banned Terms & Forbidden Vocabulary
Do **NOT** use any of the following financial or gambling terms in the code comments, variable names, UI labels, descriptions, or store assets:

| Banned Term | Reason / Concern |
| :--- | :--- |
| **stock**, **share**, **equity** | Suggests mock trading / security markets |
| **trading**, **buy**, **sell**, **short** | Implies financial speculation |
| **portfolio** | Refers to asset management |
| **profit**, **yield**, **returns**, **dividends** | Implies financial gains |
| **investment**, **investing** | Implies putting capital at risk |
| **token**, **wallet**, **coin**, **mint** | Implies cryptocurrency / tokenized systems |
| **betting**, **wager**, **gamble**, **odds** | Implies real or simulated sports/event betting |
| **karma** (in context of mechanics) | Confuses users with actual Reddit platform reputation |

---

## 🟢 Preferred Vocabulary & Terms
Always use community-focused, game-oriented terminology when writing UI text and description material:

| Banned Term Alternative | Preferred Term |
| :--- | :--- |
| Allocation Portfolio / Holdings | **Hype Picks**, **Selections** |
| Invest in / Buy a Meme | **Hype**, **Boost**, **Support** |
| Financial Pitch | **Meme Pitch**, **Contender Pitch** |
| Market / Stock list | **Hype Board**, **The Arena** |
| Submission Queue | **Launchpad** |
| Leaderboard | **Hall of Hype** |
| Community Consensus | **Crowd Drag**, **The Crowd's Choice** |

---

## 💬 Optional Social Heat Rule
* **Commenting on Reddit posts must always be optional.**
* Users can be prompted to comment/share their selections on the thread as a social interaction ("Share your hype in the comments!").
* However, sharing/commenting must **never** be required to complete the core loop, unlock points, progress in levels/streaks, or view daily results.
* Progression and game systems must function fully even if the user never posts a comment or upvotes.
